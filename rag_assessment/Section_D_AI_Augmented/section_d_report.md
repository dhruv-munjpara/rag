## Step 1: Documenting AI Prompt Used

### Prompt Submitted to AI Tool:
> *"Write a Python script using SentenceTransformers, FAISS, and PyPDF2 that loads a food delivery refund policy PDF, splits text into chunks, builds a vector index, retrieves the top chunks for a user query, and builds a system prompt for an LLM Q&A loop. Include a command-line while loop so the user can ask questions continuously."*

---

## Step 2: Code Comparison & Critical Fixes

### 1. Original Uncorrected AI Code (`ai_original_code.py`)
The initial code generated by the AI tool contained 4 critical bugs and architectural flaws:
* **Bug 1 (Mid-Sentence Chunk Slicing)**: Used raw character slicing `[text[i:i+200]]`, which blindly cut words and sentences in half (e.g., cutting `"refund"` into `"ref"` and `"und"`).
* **Bug 2 (Index Boundary Crash)**: Called `index.search(q_vec, k=5)` without checking if `k` exceeded the total number of document chunks (`len(chunks)`). If a document only had 1 chunk, FAISS crashed or returned invalid indices.
* **Bug 3 (Missing Fallback & Hallucination Vulnerability)**: The prompt template lacked negative constraint instructions, allowing the LLM to hallucinate external knowledge when the document did not contain the answer.
* **Bug 4 (Fragile Input Loop)**: The loop used exact string comparison `user_input == "quit"`, failing whenever users entered trailing spaces (`"quit "`), capitalized words (`"Quit"`), or blank lines.

### 2. Corrected & Enhanced Code (`ai_corrected_code.py`)

### 3-4 Line Note Explaining Changes & Justifications:

> **Summary of Code Improvements**:
> 1. **Word-Boundary Chunking**: Replaced character slicing with word-based overlapping chunking to preserve complete semantic sentences and prevent split keywords.
> 2. **Index Guard Rails**: Bound `k = min(k, len(chunks))` to eliminate out-of-bounds FAISS retrieval crashes when querying small documents.
> 3. **Hallucination Prevention**: Injected explicit fallback instructions (`"Answer ONLY from context; say 'I don't know' if missing"`) to enforce strict context grounding.
> 4. **Robust Input Handling**: Sanitized user input using `.strip().lower()` to handle whitespace and case variations safely.
